公式

免固攻速 = 4 - 固定攻速

免固出手 = 4 - 固定出手 - 固定攻速

最终出手 = ( 免固出手 - 免固攻速 * ( 装备攻速百分比 + buff百分比攻速 ) ) * ( 1 - 技能释放百分比)

面板攻速 = (4 - 固定攻速 ) * ( 1 - ( 装备攻速百分比 + buff百分比攻速 ) )

举例1：固定1出手、buff32攻速

免固出手 = 4 - 1 = 3

免固攻速 = 4 - 0 = 4

如果此时给你32攻速

最终出手： 3 - (4 * (0 + 0.32) ) = 1.72

那么结果是：

免固出手 = 4 - 1 = 3

免固攻速 = 4 - 0 = 4

最终出手： (3 - (4 * 0.32)) * (1-0.08) = 1.5824

如果此时固定1出手，装备给8%攻速和8%出手百分百，再加32%buff攻速

计算为：

免固出手 = 4 - 1 = 3

免固攻速 = 4 - 0 = 4

最终出手： (3 - ( 4 * ( 0.08+0.32 ) ) ) * (1-0.08) = 1.288

计算为：

免固出手 = 4 - 1(这里是固定出手) - 0.5(这里是固定攻速) = 2.5

免固攻速 = 4 - 0.5 = 3.5

最终出手：(2.5 - ( 3.5 * ( 0.08+0.32 ) ) ) * (1-0.08) = 1.012
