牛子在扩展中藏了触发器，虽然无法直接创建，但是可以通过导入的方式创建。导入的前提是你有导出的’武神扩展.json’文件，此处为我创建的两个扩展，如果想要体验一下可以直接创建导入(导入前记得把原来扩展导出，否则会覆盖消失)。
{
  "id": "bo0010814608",
  "version": "0.1",
  "items": [
    {
      "name": "无缝忙乱",
      "type": "trigger",
      "for": "data",
      "paras": "type(status);action(remove);sid(busy);id(3ju8105c57fb)",
      "content": "perform sword.chan",
      "on": {
        "bo0010814608": 1
      }
    },
    {
      "name": "检测昏迷",
      "type": "trigger",
      "for": "message",
      "paras": ".*只觉得眼前一黑",
      "content": "#msg 1",
      "on": {
        "bo0010814608": 1
      }
    }
  ]
}


可以看到，该扩展与其他扩展不同的地方在于for:data 和type:trigger ，如果是普通扩展如地图会是type:map 。

简易介绍

目前有四种类型，文本触发器、文本过滤器、事件触发器、事件过滤器，感兴趣的可以直接看网页源码。这里介绍两种触发器

1 文本

文本很简单，就是指你看到的一切消息文本，如战斗时的洪七公只觉得眼前一黑。触发器检测到后会执行相应命令。该文本有专属参数@mat ，但是实测暂时没用

2 事件

事件类型极广，几乎涵盖所有内容，如果开发到极限，可以替代脚本的触发。上述的例子为无缝缠，需要改的点为id(对应人物id)
📍
想要获取id很简单，创建一个房间物体扩展，输入#msg 该物体ID为<HIO> @id </HIO> ，点击后即可查看id
该扩展同样有专属参数@data(参数) ，对应一切数据的参数，如下可以查询拍卖数据
{
  "name": "拍卖查询",
  "type": "trigger",
  "for": "data",
  "paras": "dialog(pm)",
  "content": "#msg @data(list)",
  "on": {
   "bo0010814608": 1
  }
 },


3 参数教程

有两个点也是藏起来的：

a.运算符匹配逻辑

上次分享了不少扩展参数，但是匹配只有简单的name(名字) ，实际上还可以使用运算符如mp(>=500000) 或name(!=洪七公)

b.正则匹配逻辑

该部分作用不大(我也没搞懂)，但是也可以用在参数前后附带/ 即可启用正则。如name(/洪.*公/) 将匹配到洪七公
