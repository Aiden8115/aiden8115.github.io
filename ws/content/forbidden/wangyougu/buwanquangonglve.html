1. 每日次数：好像不限制了，有精力就能进。
  2. 年龄限制：
    • 告辞拿残页不限制年龄。
    • 超龄结婚 和超龄剧情拿紫武器不支持 20-40 岁的角色。
    • 正常结婚20-40 岁的角色。
  3. 内功注意：切勿使用带有“不灭”被动或“阴阳”技能的内功（如九阳神功、易筋经等），否则无法被“骑鹰老头”昏迷，导致流程失败。建议使用明玉功等内功。
  4. 模式：必须前台运行脚本，后台运行容易卡顿或操作延迟。
  5. 通用准备：进入副本前，请确保已装备好刀剑类武器，并设置好技能。
  • 目标：仅获取“忘忧草”，快速完成日常。
  • 流程：
    1. 跟随青青进入忘忧谷。
    2. 在谷底采集“忘忧草”。
    3. 遇到骑鹰老头时，选择挡住他。
    4. 被老头打昏迷后，等待剧情自动传送出副本。
  • 注意：此路线不触发后续任何剧情。
  • 目标：获取5张圆月弯刀残页。
  • 流程：
    1. 跟随青青进入忘忧谷，采草。
    2. 遇到骑鹰老头时，选择不挡，跟着走。
    3. 进入小楼，与青青对话后，选择告辞。
    4. 获得残页后，可选择：
      • 出副本：直接离开。
      • 杀小楼：继续挑战仇小楼（见路线五）。
  • 关键点：选择告辞后即获得残页。
  • 目标：获取紫色品质的圆月弯刀。
  • 流程：
    1. 前几步同路线二（不挡老头，进入小楼）。
    2. 在小楼，选择青青呢？。
    3. 离开小楼后，遇到仇小楼，选择后会有期。
    4. 进入山洞，即可获得紫刀。
  • 关键点：与青青对话后不要选“告辞”，选“青青呢？”。
  • 目标：获得伙伴“青青”。
  • 前置准备：背包内需有至少4棵忘忧草 和至少10壶醉仙酿。
  • 流程：
    1. 采草后，不挡老头，进入小楼。
    2. 在小楼内：
      • 正常结婚：直接与青青对话。
      • 超龄结婚：需先go south再go north触发额外对话。
    3. 对话中选择愿意留下，并答应 青青的请求。
    4. 离开小楼寻找青青，给她5棵忘忧草和10壶醉仙酿。
    5. 重要等待：开启计时器或手动等待约5分钟（月圆之时）。
    6. 等待结束后，在小楼内go west 再go east，触发青青归来。
    7. 跟随青青前往谷口，选择保护青青，即可获得青青契约。
  • 关键点：备足物品、耐心等待计时、最后一步需来回移动触发。
  • 目标：击杀仇小楼，累计一定次数后可在地窖获取残页或橙色弯刀。
  • 前置准备：
    • 准备至少10包金创药。
    • 设置好用于打小楼的内功（脚本中可选）。
    • 明确目标是累计拿弯刀残页还是拿橙刀。
  • 流程：
    1. 采草后，不挡老头，进入小楼。
    2. 切换打小楼专用内功，使用金创药，击杀仇小楼。
    3. 地窖机制（核心）：
      • 击杀后，若出现“凝听后地窖大变”提示，表示进入地窖线。
      • 进入地窖后，不要对话，直接再次kill 仇小楼 （避免其面板增强）。
      • 击杀地窖中的仇小楼后，选择领取奖励（残页或橙刀）。
      • 地窖奖励结算后，仇小楼击杀计数(TotalKills)将重置为0。
    4. 若未触发地窖，则击杀计数+1，离开副本。
  • 高阶目标：累计击杀仇小楼26次 后，触发地窖时即可选择领取橙色圆月弯刀。
  1. 分水岭：遇到骑鹰老头时，拿草线选挡，其他所有剧情线都选不挡。
  2. 小楼选择：在小楼内的第一次对话决定后续分支：
    • 告辞 -> 拿残页。
    • 青青呢？ -> 拿紫刀。
    • 答应留下 -> 结婚线。
    • 直接kill -> 杀小楼线。
  3. 地窖机制：杀小楼时，出现提示一定要下地窖，这是获取高级奖励的唯一途径。
  4. 出副本：大部分剧情结束后，使用退出副本命令安全离开。
